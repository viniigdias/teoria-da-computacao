# Simulador de Linguagens Formais e Modelos Computacionais

Projeto prático desenvolvido para a disciplina de Aspectos Teóricos da Computação. Esta aplicação interativa modela, valida e simula conceitos fundamentais da Teoria da Computação através de uma interface visual.

## ⚙️ Como Executar

O projeto foi construído utilizando Python e a biblioteca Streamlit para a interface gráfica.

1. Certifique-se de ter o Python 3.10+ instalado.
2. Clone este repositório em sua máquina local.
3. Instale as dependências listadas no projeto:
   ```
   pip install -r requirements.txt
